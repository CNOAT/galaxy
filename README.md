# Galaxy - 中文落地页模板

一个精美的响应式落地页模板，基于 Bootstrap 5，全中文界面。

## 在线预览

打开 `index.html` 即可预览，或者使用 GitHub Pages 部署。

## 特性

- 完全响应式设计，适配手机、平板、桌面端
- 基于 Bootstrap 5 框架
- 全中文界面
- 包含主视觉区、特性介绍、产品展示、用户评价、注册表单等完整模块
- 开箱即用，直接修改内容即可上线

## 本地使用

直接用浏览器打开 `index.html` 即可。

## 自定义

- **修改标题**：编辑 `<title>` 标签
- **修改导航栏**：找到 `<nav>` 部分
- **修改主标题**：找到 `<h1>` 标签
- **修改特性介绍**：找到 `features-icons` 部分
- **修改展示内容**：找到 `showcase` 部分
- **修改用户评价**：找到 `testimonials` 部分
- **修改页脚**：找到 `<footer>` 部分

## 技术栈

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
